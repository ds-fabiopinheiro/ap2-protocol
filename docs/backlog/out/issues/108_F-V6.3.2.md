## Descrição
Como **pessoa que valida no celular**
Quero **baixar o APK da versão**
Para **instalar sem Android Studio**

**Contexto:** Hoje o app só é gerado pelo Android Studio.

## Regras de negócio
- RN01 – Cada release v6.x publica um APK com o número da versão.
- RN02 – O workflow não usa segredos além dos necessários para assinar o APK de homologação.

## Fora de escopo
- Atualização automática do app.

## Critérios de aceite
- [ ] Um push de tag v6.* gera o APK no GitHub Releases.
- [ ] O APK instala em aparelho físico e abre a tela inicial.
- [ ] Uma compra com DPC é concluída em aparelho físico compatível.

## Tasks
- [Infra] Criar workflow de build do APK (Gradle) e publicação no Releases · 5 h
- [QA] Testar instalação e compra com DPC em aparelho físico · 5 h
- [Docs] Escrever instruções de instalação do APK de homologação · 2 h
