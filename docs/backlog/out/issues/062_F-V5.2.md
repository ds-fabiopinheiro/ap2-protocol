## Problema
O web client só conhece o protocolo e os artifacts do Shopping Agent v2.

## Solução proposta
Expor o Shopping Agent v1 por A2A com artifacts estruturados e configurar a URL no web client (VITE_ASSISTED_AGENT_URL).

## Usuários impactados
Pessoas que validam a jornada assistida.

## Regras de negócio
- RN01 – A jornada autônoma não muda.
- RN02 – A URL do agente da jornada assistida vem de variável VITE_*.

## Fora de escopo
- Mudança nos mandates do AP2.

## Dependências
- F-V5.1 concluída.

## Critérios de aceite
- [ ] O web client envia uma mensagem ao Shopping Agent v1 e exibe a resposta.
- [ ] Com o agente da jornada assistida fora do ar, a tela mostra erro e a jornada autônoma continua disponível.

- F-V5.2.1 · Spike: protocolo entre web client e Shopping Agent v1
- F-V5.2.2 · Escolha entre jornada autônoma e assistida na tela inicial
