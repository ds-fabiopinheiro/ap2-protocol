## Problema
O app só funciona com o aparelho ligado por USB (adb reverse para localhost) e grava a chave do Gemini no APK.

## Solução proposta
URLs do backend por configuração de build, chamadas HTTPS ao Space, chamadas ao Gemini via backend e APK publicado no GitHub Releases por workflow.

## Usuários impactados
Pessoas que validam a jornada com Digital Payment Credentials no celular.

## Regras de negócio
- RN01 – Nenhuma chave de API dentro do APK.
- RN02 – Só HTTPS para o backend.
- RN03 – APK de homologação assinado com chave de debug/homologação, não de produção.

## Fora de escopo
- Google Play.
- Suporte a aparelhos sem Credential Manager/DPC.

## Dependências
- F-V6.1 concluída.

## Critérios de aceite
- [ ] O APK publicado não contém a string da chave do Gemini (verificação por análise do APK).
- [ ] O app conclui uma compra com DPC usando o backend público da v6.
