## Descrição
Como **Shopping Agent v1 (v4)**
Quero **que o Processor Agent esteja disponível dentro do container**
Para **processar o pagamento com desafio OTP no cenário assistido**

**Contexto:** O Processor Agent pede OTP ao usuário (valor de demo 123) antes de concluir o pagamento (merchant_payment_processor_agent/tools.py).

## Regras de negócio
- RN01 – Acesso apenas por 127.0.0.1:8003.
- RN02 – O OTP de demonstração é 123.

## Fora de escopo
- OTP real por SMS ou e-mail.

## Critérios de aceite
- [ ] O agent card local em 127.0.0.1:8003 responde 200.
- [ ] Uma requisição externa ao Processor recebe 404.
- [ ] Se o Processor cair, o container reinicia.

## Tasks
- [Back] Iniciar o Processor Agent no start.sh da v3 · 2 h
- [QA] Verificar isolamento e reinício do Processor Agent · 2 h
