## Problema
O Merchant Agent (roles/merchant_agent) só roda localmente na porta 8001, sem acesso público.

## Solução proposta
Subir o Merchant Agent no container da v3, expor /a2a/merchant_agent pelo nginx com limite de requisições e agent card com URL pública.

## Usuários impactados
Desenvolvedores e integradores que validam a comunicação A2A com o Merchant.

## Regras de negócio
- RN01 – O Merchant Agent usa o modelo definido em AGENT_MODEL.
- RN02 – A rota pública /a2a/merchant_agent tem limite de 20 requisições/min por visitante.
- RN03 – As respostas do Merchant com opções de compra são assinadas com a chave do Merchant.

## Fora de escopo
- Catálogo real de produtos.
- Autenticação de chamadores.

## Dependências
- F-V3.1 concluída.

## Critérios de aceite
- [ ] GET /a2a/merchant_agent/.well-known/agent-card.json retorna 200 com a URL pública do Space.
- [ ] Uma requisição A2A de busca de produto retorna opções assinadas pelo Merchant.
- [ ] Com a mesma configuração da v2 (20 req/min, rajada de 10), a partir da 12ª requisição simultânea do mesmo visitante a resposta é 429 em JSON.

## PBIs
- F-V3.2.1 · Merchant Agent acessível por A2A com agent card público
- F-V3.2.2 · Busca de produto no Merchant Agent com resposta assinada
