## Descrição
Como **pessoa que valida a jornada assistida**
Quero **comprar um produto confirmando cada etapa**
Para **comparar a jornada assistida com a autônoma da v2**

**Contexto:** Fluxo do README do cenário: pedido → opções do Merchant → seleção → vínculo do Credentials Provider → forma de pagamento → Payment Mandate assinado → OTP → recibo.

## Regras de negócio
- RN01 – Cada etapa exige confirmação do usuário.
- RN02 – OTP de demonstração 123.
- RN03 – Os mandates da jornada são registrados com environment='v4'.

## Fora de escopo
- Endereço real de entrega.

## Critérios de aceite
- [ ] Cenário: compra concluída — Dado o ADK Web aberto, Quando o usuário completa as etapas e informa 123, Então recebe o recibo.
- [ ] Cenário: OTP incorreto — Quando o usuário informa 000, Então o pagamento não é concluído.
- [ ] Cenário: desistência — Quando o usuário recusa o carrinho, Então nenhum Payment Mandate é criado.
- [ ] Os mandates da compra concluída aparecem em ap2_env_mandates com environment='v4'.
- [ ] Com um 503 simulado na primeira chamada do Shopping Agent v1 ao modelo, a conversa continua após a nova tentativa.
