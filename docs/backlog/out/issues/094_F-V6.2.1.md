## Descrição
Como **responsável pela homologação**
Quero **trocar o backend do cenário assistido para Go por variável**
Para **comparar comportamento e consumo entre Python e Go**

**Contexto:** code/samples/go tem Makefile com `make build` e cmd/ com os entry points.

## Regras de negócio
- RN01 – Build Go em estágio separado do Dockerfile; imagem final só com os binários.

## Fora de escopo
- Otimização de imagem.

## Critérios de aceite
- [ ] O build do Space conclui com os binários Go.
- [ ] Com AP2_BACKEND_LANG=go, o log mostra os agentes Go iniciados.
- [ ] Com valor inválido, o container usa python e registra aviso.

## Tasks
- [Infra] Adicionar estágio de build Go ao Dockerfile · 5 h
- [Back] Selecionar Python ou Go no start.sh por AP2_BACKEND_LANG · 3 h
- [QA] Testar os três valores de AP2_BACKEND_LANG · 2 h
