## Problema
O Credentials Provider Agent (roles/credentials_provider_agent) não está publicado; sem ele o Shopping Agent v1 não lista formas de pagamento nem obtém a credencial.

## Solução proposta
Subir o agente na porta 8002, só interna, com a conta de demonstração do repositório (account_manager.py).

## Usuários impactados
Shopping Agent v1.

## Regras de negócio
- RN01 – Acesso apenas por 127.0.0.1:8002.
- RN02 – Só dados fictícios de demonstração.

## Fora de escopo
- Carteira real ou cartão real.

## Dependências
- F-V4.1 concluída.

## Critérios de aceite
- [ ] O agent card local em 127.0.0.1:8002 responde 200.
- [ ] Requisição externa recebe 404.
