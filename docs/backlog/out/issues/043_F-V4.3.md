## Problema
Não há como executar a jornada human-present pelo link de homologação.

## Solução proposta
Publicar o ADK Web restrito ao Shopping Agent v1, com limite de requisições, e validar a compra assistida ponta a ponta.

## Usuários impactados
Pessoas que validam a jornada assistida pelo link.

## Regras de negócio
- RN01 – O ADK Web mostra apenas o shopping_agent (v1).
- RN02 – O usuário confirma carrinho, forma de pagamento e Payment Mandate antes do pagamento.
- RN03 – O pagamento só é concluído com o OTP de demonstração 123.

## Fora de escopo
- Tela React da jornada assistida (v5).

## Dependências
- F-V4.2 concluída.
- Épico v3 concluído.

## Critérios de aceite
- [ ] A URL pública do ADK Web abre e lista só o shopping_agent.
- [ ] A compra assistida termina com recibo exibido na conversa.
- [ ] Com OTP diferente de 123, o pagamento não é concluído e a conversa informa o erro.
