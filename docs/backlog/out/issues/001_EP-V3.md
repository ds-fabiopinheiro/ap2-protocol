## Contexto
Na v2 o papel de Merchant é um servidor MCP com lógica fixa (merchant_agent_mcp). O repositório também tem o Merchant Agent (roles/merchant_agent, porta 8001) e o Merchant Payment Processor Agent (roles/merchant_payment_processor_agent, porta 8003), agentes A2A com LLM usados no cenário human-present/cards. Nenhum dos dois está publicado.

## Objetivo
Publicar os dois agentes do lado do comerciante como serviços A2A no ambiente v3, com agent card público do Merchant Agent, para servir de base à v4 (Shopping Agent v1) e permitir validar o Merchant Agent isoladamente.

## Escopo incluído
- Branch homolog-v3 e Space ap2-homolog-v3.
- Isolamento do estado por versão no Supabase (AP2_ENV).
- Merchant Agent com rota pública /a2a/merchant_agent e limite de requisições.
- Merchant Payment Processor Agent acessível só dentro do container.
- Modelo dos agentes A2A configurável por AGENT_MODEL (hoje fixo no código).
- Script de teste A2A e roteiro de QA.

## Escopo excluído
- Shopping Agent v1 e Credentials Provider Agent (v4).
- Tela no web client (v5).
- Agentes em Go (v6).

## Métrica de sucesso
- Agent card do Merchant Agent respondendo publicamente (HTTP 200).
- Script de teste A2A concluído com resposta assinada pelo Merchant em 3 execuções seguidas.
- Pico de RPM do Gemini no teste abaixo de 15.

## Dependências
- GOOGLE_API_KEY com cota disponível (plano gratuito: 15 RPM, 500 RPD, compartilhado entre Spaces).
- Resposta do caso de faturamento Google OR_CCR_53 (prevista até 03/10/2026) para decidir plano pago.

## Riscos
- A cota do Gemini é compartilhada entre v2 e v3 se usarem a mesma chave.
- O README do cenário human-present ainda cita IntentMandate/CartMandate (vocabulário da v0.1); o código usa checkout_mandate/payment_mandate. Validar o comportamento real antes de escrever os testes.
- No teste de 27/09/2026 (PR #5), o Gemini respondeu 503 UNAVAILABLE e, em outra sessão, o modelo chamou como função o nome de um JSON do prompt (product_preview_unavailable). Os agentes A2A da v3 usam o mesmo modelo e estão sujeitos aos dois erros.
