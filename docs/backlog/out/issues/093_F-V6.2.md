## Problema
Os agentes Go só rodam localmente com run.sh.

## Solução proposta
Compilar os agentes Go no Dockerfile (estágio de build Go) e escolher o backend por AP2_BACKEND_LANG=python|go.

## Usuários impactados
Desenvolvedores que comparam implementações.

## Regras de negócio
- RN01 – Padrão python; go só quando configurado.
- RN02 – Mesmas portas e rotas (8001–8003).

## Fora de escopo
- Reescrita do Shopping Agent em Go.

## Dependências
- F-V6.1 concluída.

## Critérios de aceite
- [ ] Com AP2_BACKEND_LANG=go, os agent cards de 8001–8003 são servidos pelos binários Go.
- [ ] A compra assistida conclui com backend Go.
