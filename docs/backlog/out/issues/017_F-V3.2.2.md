## Descrição
Como **integrador de agentes**
Quero **enviar um pedido de produto ao Merchant Agent e receber as opções assinadas**
Para **confirmar que o Merchant da v3 segue o AP2 antes de ligar o Shopping Agent v1**

**Contexto:** No cenário human-present o Shopping Agent v1 envia a intenção de compra ao Merchant Agent, que devolve as opções de carrinho assinadas.

## Regras de negócio
- RN01 – O teste usa só mensagens A2A com a extensão AP2 (EXTENSION_URI).
- RN02 – O teste falha se a assinatura do Merchant não verificar com a chave pública publicada.

## Fora de escopo
- Pagamento (coberto na v4).

## Critérios de aceite
- [ ] O script de teste envia a intenção de compra e recebe pelo menos uma opção assinada.
- [ ] O script verifica a assinatura e imprime OK.
- [ ] Com assinatura alterada, o script imprime FALHA e sai com código diferente de zero.
- [ ] Os mandates gerados aparecem em ap2_env_mandates com environment='v3'.

## Tasks
- [QA] Escrever script de teste A2A para o Merchant Agent · 8 h
- [Back] Levar o watch.log dos agentes para LOGS_DIR · 2 h
- [Back] Registrar no Supabase os mandates emitidos pelo Merchant Agent · 5 h
- [QA] Executar o teste 3 vezes e medir o consumo do Gemini · 2 h
