## Contexto
O web client publicado (code/web-client) só suporta a jornada autônoma do Shopping Agent v2 (FLOW card ou x402). A jornada assistida da v4 roda no ADK Web, que é uma tela de desenvolvimento.

## Objetivo
Oferecer no mesmo web client as duas jornadas do AP2 — autônoma (human-not-present) e assistida (human-present) — para comparação lado a lado.

## Escopo incluído
- Branch homolog-v5, Space ap2-homolog-v5 e projeto Vercel ap2-homolog-v5-frontend.
- Escolha da jornada na tela inicial.
- Telas da jornada assistida: opções de compra, forma de pagamento e Payment Mandate na Trusted Surface, OTP e recibo.
- Protocolo de integração entre web client e Shopping Agent v1 (definido em spike).

## Escopo excluído
- App Android (v6).
- Troca de moeda para BRL (pendência P8.1).

## Métrica de sucesso
- Compra assistida concluída pelo web client em 3 execuções seguidas.
- Compra autônoma continua passando no roteiro de regressão no mesmo web client.

## Dependências
- Épico v4 concluído.
- Tradução pt-BR do web client: PR #5 aprovado no teste de aceitação da interface em 27/09/2026, com ajustes pedidos (aviso de manter a aba aberta, mensagem de erro legível, rótulo do cartão no recibo). Mesclar antes do EP-V5 para evitar conflito de textos.

## Riscos
- O Shopping Agent v1 responde em texto livre para o ADK Web; a tela React precisa de artifacts estruturados.
- Os textos da tela podem conflitar com a tradução pt-BR se forem feitos em paralelo.
