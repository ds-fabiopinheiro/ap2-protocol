# Glossário

| Termo                                  | Sigla                                   | Definição                                                                                                                                                                                                                                                                                                | Sinônimo / Relacionado                                                                                                                                     |
| :------------------------------------- | :-------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Action Authorization                   |                                         | Processo em que um Verifier (verificador) desafia um Agent (agente) a provar que tem autorização para executar uma ação em nome de um User (usuário).                                                                                                                                                    |                                                                                                                                                            |
| Agent Payments Protocol                | AP2                                     | Protocolo aberto projetado para que agentes de IA interoperem com segurança e concluam pagamentos de forma autônoma.                                                                                                                                                                                     |                                                                                                                                                            |
| Agent Provider                         |                                         | Entidade que fornece o Agent ao User. Também pode ser uma parte confiável para que os Verifiers construam Mandates diretamente.                                                                                                                                                                          |                                                                                                                                                            |
| Agent2Agent Protocol                   | [A2A](https://a2a-protocol.org/latest/) | Padrão aberto para comunicação colaborativa e segura e gerenciamento de tarefas entre agentes de IA diferentes, independentemente dos frameworks em que foram construídos. <br><br>**Contexto:** o AP2 pode ser implementado como extensão do A2A para viabilizar transações financeiras, com foco em pagamentos por agentes que exigem alto nível de confiança. |                                                                                                                                                            |
| Agentic payments                       |                                         | Fluxos de pagamento em que agentes de IA autônomos conduzem o pagamento.                                                                                                                                                                                                                                                 |                                                                                                                                                            |
| Checkout Mandate                       |                                         | Mandate usado para autorizar a conclusão de um checkout.                                                                                                                                                                                                                                                 |                                                                                                                                                            |
| Closed Mandate                         |                                         | Mandate vinculado a uma ação específica com um Verifier, para autorizar o agente a executar essa ação.                                                                                                                                                                                              |                                                                                                                                                            |
| Credentials Provider                   | CP                                      | Entidade segura, como uma carteira digital, responsável por gerenciar e usar as credenciais de pagamento e de identidade do usuário.                                                                                                                                                                     |                                                                                                                                                            |
| Deterministic cryptographical proof    |                                         | Prova matemática única que pode ser vinculada a um dispositivo de hardware.                                                                                                                                                                                                                              |                                                                                                                                                            |
| Dynamic Linking                        |                                         | Requisito central da Strong Customer Authentication (SCA) que consiste em incluir detalhes específicos da transação em uma Payment Credential para vincular a SCA a essa transação. <br><br>**Contexto:** garante que o pagador consinta explicitamente com os detalhes da transação, como valor e beneficiário. |                                                                                                                                                            |
| Mandate Content                        |                                         | Payload específico de um Mandate, criado pelo Shopping Agent e exibido ao User, que detalha as ações que o agente executa.                                                                                                                                                                               |                                                                                                                                                            |
| Mandate Delegation                     |                                         | Processo em que um User autoriza um Agent a executar uma ação em seu nome.                                                                                                                                                                                                                               |                                                                                                                                                            |
| Mandate Receipt                        |                                         | JWT assinado pelo Verifier que indica o resultado da autorização da ação.                                                                                                                                                                                                                                |                                                                                                                                                            |
| Merchant Endpoint (Or Remote Endpoint) | ME, RE                                  | Interface web ou agente de IA que representa o vendedor, exibe produtos e negocia o carrinho.                                                                                                                                                                                                            |                                                                                                                                                            |
| Merchant Payment Processor             | MPP                                     | Entidade responsável por construir e enviar a mensagem de autorização da transação ao ecossistema de pagamentos.                                                                                                                                                                                         |  Merchant PSP                                                                                                                                                          |
| Model Context Protocol                 | MCP                                     | Protocolo que padroniza como modelos e agentes de IA se conectam e interagem com recursos externos, como ferramentas, APIs e fontes de dados.                                                                                                                                                            |                                                                                                                                                            |
| Open Mandate                           |                                         | Mandate que ainda não foi vinculado a uma ação específica. Contém constraints (restrições) a serem aplicadas a um closed mandate para garantir sua validade.                                                                                                                                                        |                                                                                                                                                            |
| Payee                                  |                                         | Pessoa ou entidade que é a destinatária prevista dos fundos de uma transação de pagamento. <br><br>**Contexto:** pode solicitar atestações junto com a confirmação do pagamento.                                                                                                                         | Merchant, Creditor Name                                                                                                                                    |
| Payer                                  |                                         | Pessoa ou entidade titular de uma conta de pagamento que autoriza uma ordem de pagamento a partir dessa conta. <br><br>**Contexto:** inicia ordens de pagamento.                                                                                                                                         | User, Holder                                                                                                                                               |
| Payment Agent                          |                                         | Papel-chave proposto para pagamentos por agentes, responsável por selecionar o método de pagamento ideal, validar os dados do pagamento e tratar erros. <br><br>**Contexto:** um Payment Agent não é obrigatório para participar do protocolo. Endpoints baseados em MCP também podem desempenhar papéis semelhantes. |                                                                                                                                                            |
| Payment Credential                     |                                         | Credencial ou instrumento (ou referência a um deles) que pode ser cobrado em um pagamento.                                                                                                                                                                                                               | Electronic Attestation of Attributes (EAA), Payment Wallet Attestation (PWA), Digital Payment Credentials (DPC), Payment Means Attestation, SPC Credential |
| Payment Initiation Service Provider    | PISP                                    | Provedor de serviços que inicia pagamentos em nome do usuário.                                                                                                                                                                                                                                           |                                                                                                                                                            |
| Payment Mandate                        |                                         | Mandate usado para autorizar o pagamento de um checkout específico.                                                                                                                                                                                                                                      |                                                                                                                                                            |
| Strong Customer Authentication         | SCA                                     | Processo exigido por marcos regulatórios para identificação online e início de transações em serviços financeiros. <br><br>**Contexto:** central no Payments Rulebook; garante a segurança e o dynamic linking das transações.                                                                           | Strong User Authentication, Integrated SCA                                                                                                                 |
| Trusted Surface                        |                                         | Interface segura, não operada por agente, que exibe o Mandate Content ao User para autorização e consentimento. O resultado é um Mandate.                                                                                                                                                                                                               |                                                                                                                                                            |
| Universal Commerce Protocol (UCP)            |                                         | Protocolo que fornece um padrão de Checkout Object quando usado com o Checkout Mandate.                                                                                                                                                                                                                  |                                                                                                                                                            |
| User                                   |                                         | A pessoa que inicia a tarefa e concede a autoridade financeira.                                                                                                                                                                                                                                          |                                                                                                                                                            |
| User Agent a.k.a. Shopping Agent       | UA, SA                                  | A superfície de IA que interage diretamente com o usuário, entende suas necessidades e coordena a compra.                                                                                                                                                                                                |                                                                                                                                                            |
| Verifiable digital credential          | VDC                                     | Credencial assinada por um Issuer (ou seja, um conjunto de Claims) cuja autenticidade pode ser verificada. <br><br>**Contexto:** normalmente vinculada a uma chave criptográfica e usada no modelo issuer-holder-verifier.                                                                               | Digital credential, Verifiable Credential                                                                                                                                         |
| Verifiable Presentation                | VP                                      | Apresentação de uma ou mais VDCs que inclui uma prova criptográfica de vínculo com o holder, criada em resposta a uma solicitação de um Verifier. <br><br>**Contexto:** permite que um Verifier confirme que o Holder destinou a apresentação a ele e pode revelar apenas parte das claims.               |                                                                                                                                                            |
