# Política de segurança

Para relatar um problema de segurança, use [g.co/vulnz](https://g.co/vulnz).

A Google Security Team responderá em até 5 dias úteis após o seu relato em g.co/vulnz.

Usamos o g.co/vulnz para o recebimento dos relatos, e a coordenação e a divulgação são feitas aqui, com o GitHub Security Advisory, para discutir e corrigir o problema de forma privada.
